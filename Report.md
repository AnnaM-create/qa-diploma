Отчет о тестировании

Краткое описание
Проведено автоматизированное тестирование комплексного сервиса покупки тура "Путешествие дня". Приложение протестировано по двум сценариям: оплата по дебетовой карте и выдача кредита по данным карты. Тестирование проводилось с подключением к базе данных MySQL.

Количество тест-кейсов
Всего написано и автоматически пройдено 29 тест-кейсов (позитивные, негативные сценарии, проверка валидации полей, проверка записи в БД и проверка архитектуры приложения).

Результаты тестирования
Успешных тест-кейсов: 15 (51%)
Неуспешных тест-кейсов: 14 (49%)

Общие рекомендации
1. Исправить критические баги, связанные с отображением уведомлений об ошибке при оплате отклоненными картами (DECLINED) как при обычной оплате, так и при кредите.
2. Исправить баг валидации поля "Месяц" (принимает значение "00").
3. Исправить критические баги валидации поля "Владелец" - отсутствие проверки на кириллицу, спецсимволы, длину строки и ввод только имени без фамилии.
4. Исправить баг валидации длины номера карты (обрезание 17-й цифры).
5. Часть тестов упала из-за нестабильности приложения при массовом прогоне тестов
Подробное описание найденных дефектов находится во вкладке Issues репозитория.
