Дипломный проект: автоматизация тестирования комплекса услуг "Путешествие дня"

Инструкция по запуску автотестов

Подготовка окружения
1. Убедитесь, что установлены: Java JDK 17+, Node.js, IntelliJ IDEA, MySQL.
2. В MySQL создайте базу app и пользователя app с паролем pass.

Запуск приложения (SUT)
1. Открыть проект в IntelliJ IDEA.
2. В терминале перейти в папку эмулятора: cd gate-simulator
3. Запустить эмулятор банка: npm start
4. Открыть новую вкладку терминала (в корне проекта) и запустить приложение: java -jar artifacts/aqa-shop.jar
5. Дождаться сообщения Started ShopApplication.

Запуск автотестов
1. В IDEA нажать Run на классе PaymentTest или выполнить в терминале команду:./gradlew clean test

Просмотр отчета
1. После прогона тестов открыть файл в браузере:`build/reports/tests/test/index.html
