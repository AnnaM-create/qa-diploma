# Дипломный проект: Автоматизация тестирования "Путешествие дня"

## О проекте
Веб-сервис, который предлагает купить тур двумя способами:

**Обычная оплата** по дебетовой карте.

**Уникальная технология:** выдача кредита по данным банковской карты.

## Инструкция по запуску автотестов
## Подготовка окружения

Убедитесь, что установлены:

Java JDK 17+

Node.js

IntelliJ IDEA

MySQL

## 2. Настройка базы данных
В MySQL создайте базу и пользователя со следующими параметрами:

**Название базы:** app

**Имя пользователя:** app

**Пароль:** pass

## 3. Запуск приложения (SUT)

1. Открыть проект в IntelliJ IDEA.
2. В терминале перейти в папку эмулятора: cd gate-simulator
3. Запустить эмулятор банка: npm start
4. Открыть **новую вкладку** терминала и запустить приложение: java -jar artifacts/aqa-shop.jar
5. Дождаться сообщения Started ShopApplication.
   
   
## 4. Запуск автотестов
В IDEA нажать Run на классе PaymentTest или выполнить в терминале команду:

./gradlew clean test

## 5. Просмотр отчета
После прогона тестов открыть файл в браузере:
